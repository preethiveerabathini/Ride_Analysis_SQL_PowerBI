# 🚗 Ride Analysis — SQL & Power BI

## 📌 Project Overview

This project analyzes ride booking data to uncover booking trends, revenue performance, customer behavior, cancellation patterns, and key business insights.

SQL was used for data analysis and KPI calculations, while Power BI was used to create an interactive dashboard.

## 🛠️ Tools & Technologies

- SQL / MySQL
- Power BI
- Excel / CSV
- Data Cleaning
- Data Analysis
- Data Visualization

## 🎯 Business Questions

- What is the total number of rides?
- What are the most popular ride types?
- What are the booking and cancellation rates?
- Which locations have the highest ride demand?
- What are the revenue trends?
- What are the main reasons for ride cancellations?
- How does ride demand change over time?

## 🔍 SQL Analysis

SQL was used to:

- Clean and analyze the dataset
- Calculate key performance indicators (KPIs)
- Analyze ride demand and booking trends
- Identify cancellation patterns
- Analyze revenue performance
- Compare different ride types
- Analyze customer and driver trends

## 📊 Power BI Dashboard

The Power BI dashboard provides interactive visualizations for:

- Total Rides
- Completed Rides
- Cancelled Rides
- Revenue
- Ride Type Analysis
- Cancellation Analysis
- Location Analysis
- Time-based Trends

## 💡 Key Insights

- Identified the most frequently used ride types.
- Analyzed ride completion and cancellation patterns.
- Identified locations with higher ride demand.
- Analyzed revenue performance across different ride categories.
- Identified major cancellation factors.
